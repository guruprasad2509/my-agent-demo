# my-agent-demo

Multi agent Code basics - Hands on

## Overview

`my-agent-demo` is a showcase repository demonstrating how to build multi‑agent systems using the **OpenAI function‑calling** paradigm. It includes examples of agents that can read, write, and modify files, search code, and collaborate to accomplish complex tasks.

---

## Recent Features

- **Documentation Agent**: Added a new documentation agent that can automatically generate and update project docs, README, API references, and more.
- **Branch Management Utilities**: Functions to create, switch, and list branches directly from the agent.
- **File Operations**: Enhanced support for reading, creating, and updating files with clear formatting rules.
- **Search & Navigation**: Ability to search codebase and list directory contents, facilitating large projects.
- **Pull‑Request Simulation**: Agents can now prepare changes ready to be submitted as a pull request.

## Usage Example

Below is a minimal example of how to invoke the documentation agent to update the README:

```python
from agents import DocumentationAgent

agent = DocumentationAgent()

# The agent will:
# 1. Read the current README
# 2. Append a "Recent Features" section
# 3. Commit the changes on a new branch
# 4. Prepare a pull‑request payload (simulated)

agent.run()
```

The agent will automatically:
1. **Read** the existing `README.md`.
2. **Create a new branch** (e.g., `doc/update-readme`).
3. **Update** the file with the new content.
4. **Output** a summary of the changes ready for a PR.
